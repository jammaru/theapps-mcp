---
title: Configuration
description: Environment variables for Apps-mcp.
---

| Variable | Required | Description |
|------|------|------|
| `APPS_APP_ID` | yes* | App ID |
| `APPS_APP_SECRET` | yes* | App Secret |
| `APPS_ACCESS_TOKEN` | no | Fixed bearer |
| `APPS_MCP_ALLOW_WRITE` | no | Allow writes (default `false`) |
| `APPS_API_BASE_URL` | no | Default `https://api.theapps.jp` |

\* or `APPS_ACCESS_TOKEN`
